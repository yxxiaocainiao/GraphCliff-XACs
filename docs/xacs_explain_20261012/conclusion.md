## 这一轮排除了什么

此前的 ACA、cosine-margin 先导都受"每批几乎没有监督信号"困扰（随机三元组挖掘只有 5 个候选、82/83 批为空，辅助/回归梯度范数比 0.02–0.04%）。本轮把监督换成 XACs 的原子级标注后：

- 每批约 **38 条配对、约 980 个被标注原子**，全部任务在 100 轮 × 3 种子的覆盖检查里每批都有配对；
- 冻结权重 w=0.01 时辅助/回归梯度范数比 **2.4–3.4%**（是历史轮次的约 100 倍），梯度夹角约 0.83；
- 首轮约 1/3 的铰链项处于激活状态。

在这个密度下，验证 Cliff/Overall 仍一致略差。因此"损失侧没效果只是因为监督太稀疏/系数太小"这一解释，对**解释监督这条具体路径**不再成立；不能反过来否定其它监督形式。

## 机制诊断（弱证据，样本很小）

`experiments/xacs_explain/diagnose.py` 用**验证集内部**配对（不参与训练，标签仅用于诊断）比较两臂的逐原子 GradCAM 归因：

| Task | 验证内配对 | hinge 满足率 mse→explain | uncommon 归因占比 mse→explain |
|---|---:|---|---|
| CHEMBL234_Ki | 54 | 0.514 → 0.244 | 0.669 → 0.758 |
| CHEMBL2147_Ki | 32 | 0.393 → 1.000 | 0.316 → 0.333 |
| CHEMBL244_Ki | 32 | 0.625 → 无有效对 | 0.120 → 0.000 |
| CHEMBL2047_EC50 | 0 | — | — |

- 结论只能说：**干预确实改变了归因行为**（两臂在这些指标上明显不同），但方向不一致，且没有转化成预测收益。
- 样本极小（0–54 对，CHEMBL244 的 explain 臂甚至没有任何"不常见原子质量非零"的对），不能据此下机制结论。
- 一个待检验假设（本轮**未**验证）：ACES 的 common 项在全体共有原子上求和，而 MoleculeACE 的悬崖对往往是"大骨架相同、只差一个取代基"，该求和近似"全分子压制归因"，可能把不常见原子的信号一起压掉；CHEMBL244 explain 臂 uncommon 归因占比为 0 与这一猜测方向一致，但需要对多项做归一化/分区的对照实验才能判定。

## 边界

- 监督只用开发 train 内部配对；官方 test 未参与训练、挖掘、选型，本轮**未评价 test**。上表是开发验证成绩，不与论文数字并列。
- 三种子共用同一划分，只估计初始化变动；验证集参与选模。
- 损失形式来自 ACES-GNN（Digital Discovery 2025，`github.com/Liu-group/XACs`），本项目只做接入与受控比较，不宣称原创或复现。
- 权重 w=0.01 由事前规则（梯度范数比最接近 2%）冻结，未在验证集上搜索；本轮无超参搜索、无自动扩大。

## 决策

按冻结协议：**暂停该配方**，不自动调 w、不加模块、不扩到 30 任务或 test 评价。若后续要继续，最小可行下一步是上一条"待检验假设"的受控对照（common 项归一化/只在配对局部求和），或改用 GraphCliff 自带的逐原子 gate 作为监督目标；两者都需要先写新的冻结协议，不能用本轮结果事后选方向。
